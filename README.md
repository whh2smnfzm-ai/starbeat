# 🌙 스텔라 비트: 밤의 사냥꾼들

낮에는 아이돌, 밤에는 악마 사냥꾼! 선택에 따라 결말이 달라지는 모바일 친화형 비주얼 노벨입니다.

## 플레이
`index.html`을 브라우저로 열면 바로 실행됩니다. (별도 설치 없음)

### GitHub Pages로 배포
1. 저장소 Settings → Pages
2. Branch를 `main` / `(root)`로 선택 후 저장
3. 발급된 주소로 접속

## 특징
- 탭으로 진행하는 대사 시스템
- 신뢰 / 용기 수치에 따라 갈리는 엔딩 3종
- 외부 라이브러리 없는 단일 HTML 파일

## 참고
케이팝 + 악마 사냥 분위기에서 영감을 받은 팬 창작 프로젝트이며, 캐릭터·스토리는 모두 오리지널입니다. 원작의 캐릭터, 곡, 이미지는 사용하지 않았습니다.
